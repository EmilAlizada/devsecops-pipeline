# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for a suspected vulnerability.

Report security concerns privately to **alizadaemil404@gmail.com** with the affected component, impact, and safe reproduction steps.

This is a portfolio and learning project, not a production service. Responsible disclosure practices are intentionally documented and followed.

## Scope

Application code, container configuration, CI workflows, and dependency configuration are in scope.

Do not test systems you do not own or have explicit authorization to assess.
